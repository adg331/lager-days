# 喝了么 · LAGER DAYS

线上地址：https://adg331.github.io/lager-days/ （GitHub Pages，源自本仓库根目录的 `index.html`）

主要面向 iPhone 的设备本机啤酒日记。数据仅写入当前浏览器 localStorage，不上传饮酒记录或导入的备份；无账号体系。

## 使用

在 Safari 打开发布网址，通过「分享 → 添加到主屏幕」使用。固定在同一浏览器/主屏幕入口记录；存储不保证跨入口共享。通过「设置与备份 → 导出完整备份」保存 JSON 到文件或 iCloud Drive。更换设备后导入，默认合并同一 ID 并以修改时间选择新值。删除标记参与合并，避免旧备份恢复已删除记录。JSON 是完整备份；CSV 仅为记录表，不支持恢复。

public/lager-diary.html 是包含图片、样式和脚本的单文件版本，可放到任何静态 HTTPS 网站。iPhone 文件预览器不等同于浏览器，日常使用推荐固定 HTTPS 网址。单文件与主应用复用同一组件及数据模型，不包含演示记录。

## 运行与验证

Node >=22.13。npm ci；npm run dev；npm run build。node --experimental-strip-types --test lib/diary.test.ts；npx tsc --noEmit。生成单文件：node scripts/export-html.mjs，同时写入 standalone-build/喝了么.html、根目录 index.html（GitHub Pages 的入口）和 public/lager-diary.html，三份内容相同。改完代码跑一次该脚本再提交，推送后 Pages 会自动重新构建。产物本身被提交，因此 app/globals.css 用 `@source not` 把 index.html 和 public/lager-diary.html 排除在 Tailwind 扫描之外，否则上一次产物里的压缩字符串会被当成 class 生成多余 CSS，导致全新构建与增量构建结果不一致。

## 统计口径

按当地日期保存，mL 使用整数。未记录与明确未饮酒分开。记录完整确认会把空日期标记为未饮酒，写入前明确提示；新增、编辑和删除会使受影响日期重新待确认。世界页面把所选年份的实际累计量和“实际累计量 ÷ 已过日历日 × 全年日历日”的全年估算一并加入国家对比，并按数值降序排列；记录不完整时估算可能偏低。酒杯动效开关同时控制图片呼吸、气泡、倒酒闪光和数字过渡，并保存到本机偏好。

## 数据清理与导入撤销

每次成功合并或替换备份前，应用会在浏览器中保存一份导入前快照；只保留最近一次。撤销导入会先下载当前完整备份，再把整个日记恢复到导入前，因此导入后新增或修改的内容也会回退。清空全部记录会先下载当前完整备份，再清空 entries 与 days，保留 prefs 和 lastBackup；清空后移除导入撤销快照。

年度分享位于“世界”页，页面内先展示一张 iOS 极简风年度回顾卡；点击后生成适配 iPhone 17 Pro Max 竖屏的 1320×2868 PNG，包含饮酒日、饮酒次数、500 mL 标准罐换算，以及捷克、德国、英国、中国和个人实际消费五条对比。分享图片不显示全年估算。支持文件分享的 Safari 会打开系统分享菜单，其余浏览器下载 PNG。

首页和年度分享背景使用 ImageGen 生成的 iOS 极简风原创 3D 酒杯（`public/beer-ios-v3.png` / `.jpg`），酒杯完整位于右侧，左侧保留文字安全区。年度分享图采用浅灰、白色半透明卡片和简洁层级，左上角是“麦”印章加“喝了么”的品牌标识，放在酒杯左侧的安全区内；五条对比按数值排序并标注“第 N 名”，名次文字与条形按实测宽度排布，不重叠。主屏幕图标使用确认后的 iOS 原生简约啤酒杯（`public/app-icon-ios-v4.png`），并提供 512、192 和 180 px 资源。

## 国家数据

Kirin《Global Beer Consumption by Country in 2024》Table 3，2025-12-22 发布：
https://www.kirinholdings.com/en/newsroom/release/2025/1222_01.html
捷克148.8、德国86.9、英国66.3、美国65.4、韩国44.6、日本33.7 L/人/年，来自 Kirin 人均表。中国以 Kirin 2024 总消费量 4,053.4 万千升除以国家统计局年末大陆人口 14.0828 亿，计算为约 28.8 L/人/年。总人口口径包含非饮酒者；日本包括啤酒、发泡酒、新类型酒类，不能视为纯拉格或纯酒精量。

## 验证记录

模型测试覆盖跨月跨年、闰年、日期校验、撤销、备份往返、重复合并、较新记录覆盖、删除标记、估算门槛、CSV转义。浏览器验证覆盖375/390/430 CSS px宽度、330/500快速记录、撤销、刷新保存、自定义容量、跨月补记、完整确认、重复导入、无效备份拦截和估算。WebMCP只读日期汇总工具通过有效/无效输入验证。未使用iPhone真机验证；内置浏览器未返回下载事件，导出文件最终落盘仍需Safari实机确认。没有真实用户数据参与测试。
