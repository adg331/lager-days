# 拉格日记

主要面向 iPhone 的设备本机啤酒日记。数据仅写入当前浏览器 localStorage，不上传饮酒记录或导入的备份；无账号体系。

## 使用
在 Safari 打开发布网址，通过「分享 → 添加到主屏幕」使用。固定在同一浏览器/主屏幕入口记录；存储不保证跨入口共享。通过「设置与备份 → 导出完整备份」保存 JSON 到文件或 iCloud Drive。更换设备后导入，默认合并同一 ID 并以修改时间选择新值。删除标记参与合并，避免旧备份恢复已删除记录。JSON 是完整备份；CSV 仅为记录表，不支持恢复。

public/lager-diary.html 是包含图片、样式和脚本的单文件版本，可放到任何静态 HTTPS 网站。iPhone 文件预览器不等同于浏览器，日常使用推荐固定 HTTPS 网址。单文件与主应用复用同一组件及数据模型，不包含演示记录。

## 运行与验证
Node >=22.13。npm ci；npm run dev；npm run build。node --experimental-strip-types --test lib/diary.test.ts；npx tsc --noEmit。生成单文件：node scripts/export-html.mjs，产物 standalone-build/拉格日记.html；发布前复制到 public/lager-diary.html。

## 统计口径
按当地日期保存，mL 使用整数。未记录与明确未饮酒分开。记录完整确认会把空日期标记为未饮酒，写入前明确提示；新增、编辑和删除会使受影响日期重新待确认。全年估算需要至少30个连续、完整确认且不含今天的日期；公式为区间总量/区间天数×结束年份日历天数。世界图表单位 L/人/年；不会直接把未满年累计量叠入全年人均对比。

## 验证记录
模型测试覆盖跨月跨年、闰年、日期校验、撤销、备份往返、重复合并、较新记录覆盖、删除标记、估算门槛、CSV转义。浏览器验证覆盖375/390/430 CSS px宽度、330/500快速记录、撤销、刷新保存、自定义容量、跨月补记、完整确认、重复导入、无效备份拦截和估算。WebMCP只读日期汇总工具通过有效/无效输入验证。未使用iPhone真机验证；内置浏览器未返回下载事件，导出文件最终落盘仍需Safari实机确认。没有真实用户数据参与测试。
